# Language Features for Markdown files

This extension is bundled with NPad.

## Features

See the [upstream Markdown documentation](https://code.visualstudio.com/docs/languages/markdown) for background on this extension. NPad includes local Markdown editing and previews within its documented product scope.

## Testing

Run `pnpm run test-editor-title` from this directory to verify that the source and preview title actions keep a consistent order alongside Git's Open Changes action.
